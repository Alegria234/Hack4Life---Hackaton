## 📂 Arquitectura del Repositorio

El proyecto utiliza una estructura de **Monorepo** para mantener frontend y backend unificados, facilitando la integración rápida:

*   **`/frontend`**: Interfaz de usuario construida con **React + Vite** (JavaScript). Linter configurado con ESLint para evitar errores bajo presión.
*   **`/backend`**: API y lógica de servidor utilizando **Node.js**.
